# HANURI

A Vue 3 application scaffolded with Quasar Framework, Vite, TypeScript, Vue Router, and Pinia.

## Requirements

- Node.js 20 or later
- npm

## Setup

```sh
npm install
npm run dev
```

The Quasar development server prints its local URL when it starts.

## Commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run typecheck` checks TypeScript and Vue types.
